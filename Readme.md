# Отчет по лабораторной работе №1: Цветовые модели

**Цель работы:** Изучить цветовые модели RGB, CMYK и HLS и реализовать интерактивное приложение-конвертер, обеспечивающее двустороннее преобразование между ними.

**Среда разработки:** Python 3 + Tkinter.

---

## 1. Общая структура приложения

Приложение `ColorApp` реализовано на базе **Tkinter** и использует три основные панели для каждой цветовой модели. Все компоненты (ползунки, поля ввода) связаны переменными `tk.DoubleVar`.

### Ключевой принцип: Единый источник истины
Основной цвет приложения всегда хранится в модели **RGB** (`self.current_rgb`). При любом изменении (слайдер, поле ввода, палитра) цвет сначала нормализуется в RGB, а затем уже из этого эталонного значения пересчитываются и обновляются CMYK и HLS. Это гарантирует согласованность всех трех моделей.

---

## 2. Реализация требований к интерфейсу и функциональности

### 2.1. Интерактивность
Приложение обеспечивает три способа задания и изменения цвета для каждой модели:
1.  **Ползунки (`Scale`):** Позволяют плавно изменять значения компоненты.
2.  **Поля ввода (`Entry`):** Позволяют задавать точные, целочисленные значения.
3.  **Палитра (`colorchooser`):** Кнопка "Выбрать из палитры" вызывает стандартный системный диалог выбора цвета.

### 2.2. Автоматический пересчет
Реализована функция `process_change(model)`, которая вызывается при любом изменении (ввод текста или движение ползунка).
* Эта функция определяет, какая модель была изменена (`RGB`, `CMYK` или `HLS`).
* Вызывает соответствующую функцию конвертации (например, `cmyk_to_rgb`).
* Передает полученное RGB-значение в главную функцию обновления `update_all_from_rgb()`, которая затем пересчитывает и обновляет значения двух других моделей.
* Использование флага `self.updating` предотвращает рекурсивные вызовы при автоматическом обновлении компонентов.

### 2.3. Дружелюбный и удобный интерфейс
* **Визуализация:** Отображается образец цвета (`color_display`) в виде прямоугольника.
* **Структура:** Интерфейс разделен на три логических фрейма с заголовками (`RGB`, `CMYK`, `HLS`).
* **Диапазоны:** Ползунки и поля ввода ограничены корректными диапазонами для каждой компоненты:
    * RGB: $0-255$.
    * CMYK: $0-100\%$.
    * HLS: H ($0-360^\circ$), L, S ($0-100\%$).

## 3. Корректность перевода и математические модели (40 баллов)

### 3.1. Преобразование RGB $\leftrightarrow$ CMYK

Модель CMYK является субтрактивной (вычитающей цвет) и используется в полиграфии. Компоненты (Cyan, Magenta, Yellow, Key/Black) представляют собой доли чернил, вычитаемых из белого.

#### RGB $\to$ CMYK
Формулы требуют нормализации RGB-компонент $r', g', b'$ в диапазон $[0, 1]$ и вычисления ключевого цвета $K$.
$$r' = R/255, \quad g' = G/255, \quad b' = B/255$$
$$K = 1 - \max(r', g', b')$$
Если $K=1$ (чистый черный), то $C=M=Y=0$. Иначе:
$$C = \frac{1 - r' - K}{1 - K}$$
$$M = \frac{1 - g' - K}{1 - K}$$
$$Y = \frac{1 - b' - K}{1 - K}$$
Все компоненты CMYK масштабируются до $100\%$.

#### CMYK $\to$ RGB
Для перевода обратно используется обратная логика:
$$R = 255 \times (1 - C) \times (1 - K)$$
$$G = 255 \times (1 - M) \times (1 - K)$$
$$B = 255 \times (1 - Y) \times (1 - K)$$
Компоненты $C, M, Y, K$ используются в диапазоне $[0, 1]$.

### 3.2. Преобразование RGB $\leftrightarrow$ HLS

Модель HLS (Hue, Lightness, Saturation) — это цилиндрическая модель, удобная для восприятия человеком.

#### RGB $\to$ HLS и HLS $\to$ RGB
Для этих преобразований в Python целесообразно использовать встроенный модуль `colorsys`, который гарантирует высокую точность и корректность вычислений.

* `colorsys.rgb_to_hls(r, g, b)`: Использует нормализованные RGB-компоненты $[0, 1]$ и возвращает H, L, S в диапазоне $[0, 1]$.
* `colorsys.hls_to_rgb(h, l, s)`: Использует H, L, S в диапазоне $[0, 1]$ и возвращает нормализованные RGB-компоненты.

**Масштабирование для интерфейса:**
Поскольку компоненты HLS в `colorsys` находятся в диапазоне $[0, 1]$, для отображения в пользовательском интерфейсе они масштабируются:
* $H$: $[0, 1] \times 360^\circ$
* $L, S$: $[0, 1] \times 100\%$

Это обеспечивает интуитивно понятное отображение для пользователя.

### Ключевые компоненты HLS
* **Hue (Оттенок - H):** Задает чистый цвет, меняется по кругу от $0^\circ$ (красный) до $360^\circ$.
* **Lightness (Яркость - L):** Определяет, насколько цвет светлый или темный. $L=0$ — черный, $L=100$ — белый.
* **Saturation (Насыщенность - S):** Определяет чистоту цвета. $S=0$ — серый, $S=100$ — чистый цвет.
