## 1. Постановка задачи
Целью работы является закрепление теоретического материала и практическое освоение основных возможностей по использованию базовых алгоритмов растеризации. 

Необходимо реализовать приложение, иллюстрирующее работу 4-х алгоритмов:
1. Пошаговый алгоритм.
2. Алгоритм ЦДА (DDA).
3. Алгоритм Брезенхема (отрезок).
4. Алгоритм Брезенхема (окружность).

Требования к интерфейсу включают наличие координатной сетки, осей, подписей и возможность масштабирования. Также необходимо провести анализ временных характеристик.

## 2. Реализация приложения
Приложение разработано на языке **Python** с использованием библиотеки **Tkinter**.

### Особенности реализации интерфейса
* **Сетка:** Реализована динамическая отрисовка сетки с шагом, заданным переменной `pixel_size`.
* **Координаты:** Экранные координаты преобразуются в логические (декартовы). Центр координат $(0,0)$ размещен в центре окна. Ось $Y$ инвертирована относительно стандартных экранных координат.
* **Визуализация:** Пиксели имитируются прямоугольниками ("жирными точками").

## 3. Описание алгоритмов

### 3.1. Пошаговый алгоритм (Step-by-Step)
Алгоритм основан на непосредственном использовании уравнения прямой:
$$y = kx + b$$
где $k = \frac{\Delta y}{\Delta x}$.

**Проблема:** При $|k| > 1$ (угол наклона > 45°) изменение $x$ на 1 приводит к изменению $y$ больше чем на 1, что вызывает разрывы линии.
**Решение:** В реализации добавлена проверка ведущей оси.
* Если $|\Delta x| \ge |\Delta y|$, цикл идет по $x$.
* Если $|\Delta y| > |\Delta x|$, цикл идет по $y$, вычисляя $x = \frac{y-b}{k}$.

### 3.2. Алгоритм ЦДА (DDA - Digital Differential Analyzer)
 Вместо полного вычисления уравнения на каждом шаге, координаты увеличиваются на фиксированное приращение.

**Реализация:**
1.  Вычисляется длина пути `length` = $\max(|\Delta x|, |\Delta y|)$.
2.  Вычисляются шаги приращения:
    $$dx_{step} = \frac{\Delta x}{length}, \quad dy_{step} = \frac{\Delta y}{length}$$
3.  Координаты хранятся как вещественные числа (`float`), а для отрисовки округляются (`round`).

### 3.3. Алгоритм Брезенхема для отрезков
Наиболее оптимизированный алгоритм, использующий **только целочисленную арифметику**. Решение о выборе следующего пикселя принимается на основе знака накапливаемой ошибки.

**Принцип работы:**
* Инициализируется переменная ошибки $err = \Delta x - \Delta y$.
* На каждом шаге проверяется удвоенная ошибка $e2$.
* В зависимости от знака $e2$, делается шаг по $x$ или по $y$, и значение ошибки корректируется.
* Реализация поддерживает отрисовку во всех 8 октантах за счет учета знаков направления (`sx`, `sy`).

### 3.4. Алгоритм Брезенхема для окружности
Алгоритм строит окружность $x^2 + y^2 = R^2$ без использования тригонометрии и квадратных корней.

**Особенности реализации:**
1.  **Симметрия:** Вычисляются точки только для одного октанта (0–45°). Остальные 7 точек получаются зеркальным отражением (8-сторонняя симметрия).
2.  **Параметр решения:** Используется дискриминант $d$. Начальное значение $d = 3 - 2R$.
3.  **Итерация:**
    * Если $d > 0$ (выход за пределы), выбирается диагональный пиксель (сдвиг $y$), $d$ увеличивается на $4(x-y) + 10$.
    * Иначе выбирается горизонтальный пиксель, $d$ увеличивается на $4x + 6$.

## 4. Сравнительный анализ и временные характеристики

Время выполнения замерялось с использованием `time.perf_counter_ns()` (в микросекундах).

| Алгоритм | Тип арифметики | Сложность | Примечание |
| :--- | :--- | :--- | :--- |
| **Пошаговый** | Вещественная (`float`) | Высокая | Требует умножения и округления на каждом шаге. |
| **ЦДА (DDA)** | Вещественная (`float`) | Средняя | Требует сложения вещественных чисел. |
| **Брезенхем** | Целочисленная (`int`) | Низкая | Только сложение, вычитание и сдвиги. Самый быстрый. |

**Вывод:**
Алгоритм Брезенхема является наиболее эффективным для машинной графики, так как избегает дорогих операций деления и работы с плавающей точкой, что подтверждается теоретическими данными и замерами времени в приложении.
